# AI-консьерж для автодетейлинга — план v0.1

Первый бот фермы. Задача — архитектура, которую потом клонируем под другие ниши
(аренда, услуги) сменой конфига и базы знаний, а не переписыванием workflow.

## 0. Инструменты (этап «скиллы»)

| Что | Зачем | Установка (локальный терминал) |
|---|---|---|
| **n8n-mcp** (czlonkowski) | Claude видит все ноды n8n и их параметры, валидирует JSON, создаёт и обновляет workflow прямо в твоём n8n по API | `npx n8n-mcp` + `N8N_API_URL=http://localhost:5678`, `N8N_API_KEY=...` |
| **n8n-skills** (czlonkowski) | Скиллы под n8n-mcp: паттерны workflow, выражения, Code-ноды, валидация, AI Agent | `/plugin install czlonkowski/n8n-skills` |
| **n8n-io/skills** (официальный) | Альтернатива: нужен n8n ≥ 2.2.0 со встроенным MCP | `/plugin marketplace add n8n-io/skills` → `/plugin install n8n-skills@n8n-io` |
| Мод: `/n8n-push`, `/n8n-pull` | Синхронизировать JSON из git ↔ n8n одной командой | сделаем через plugin-authoring |
| Хук pre-commit | Валидировать workflow JSON до коммита (ловит сломанные связи и выражения) | сделаем |

Брать **один** пакет скиллов, не оба: при n8n ≥ 2.2 — официальный, иначе — czlonkowski.

## 2. Архитектура (модульные workflow)

```
IG / FB / WA / TG ──► WF-01 Ingress ──► WF-02 Brain (AI Agent) ──► WF-03 Outbound ──► канал
                       нормализация        инструменты:                 отправка по каналу
                       дедупликация         • свободные слоты
                       склейка пачки        • создать / перенести / отменить
                       пауза бота           • прайс и услуги (база знаний)
                                            • позвать человека ──► WF-04 Handoff (Telegram)
WF-05 Scheduler (каждые 5 мин): напоминания клиенту, владельцу, мастеру
WF-06 Sheets Sync: Postgres ──► Google Sheets
WF-99 Error Handler: любая ошибка ──► Telegram-алерт + лог
```

Принципы:
- Единый формат сообщения из любого канала: `{channel, user_id, conversation_id, text, media, ts}`.
- Брони пишутся в Postgres с блокировкой слота, чтобы два клиента не взяли одно время. Sheets — витрина, не источник истины.
- Бот не придумывает цены и время: только через инструменты.
- Handoff: при низкой уверенности, жалобе, «позовите человека», нестандартной услуге, на 2-м непонимании подряд — бот ставит паузу на диалог и шлёт админу карточку с историей.
- Каждое действие пишется в `events` (лог) — проверять и анализировать проще.
- Конфиг бизнеса (услуги, цены, длительности, мастера, часы работы, тон) — в таблице `business_config`, workflow одинаковые для всех клиентов фермы.

## 3. Напоминания

| Кому | Когда | Канал |
|---|---|---|
| Клиент | за 24 ч (подтверждение «Да / Перенести») и за 3 ч | канал записи; WA — шаблоном |
| Владелец | за 3 ч: кто, что, какой мастер | Telegram |
| Мастер | за 3 ч + утренняя сводка дня | Telegram |
| Клиент | после визита +1 день: отзыв / Google review | канал записи |

## 4. Порядок работ

1. Поставить n8n-mcp + скиллы, проверить, что Claude видит твой n8n.
2. docker-compose: n8n + Postgres + cloudflared. Схема БД.
3. WF-99 Error Handler и WF-04 Handoff — первыми, чтобы всё дальше было под наблюдением.
4. WF-02 Brain + Telegram как тестовый канал (самый быстрый для отладки).
5. WF-01/03 для Instagram, затем WhatsApp (верификация Meta занимает дни — запускаем параллельно с п. 2).
6. WF-05 напоминания, WF-06 Sheets.
7. Тестовый прогон: 30 сценариев диалога (запись, перенос, торг, жалоба, мусор, голосовое, фото машины).
8. Шаблонизация под следующую нишу.
